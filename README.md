# Chalculator: How To Play
Players see the numbers, operators, and the answer to the equation and have to guess the original equation.
# Current Features
<ul>Difficulty Setting </ul>
<ul>Answer Display </ul>
<ul>Error Bound to Accept Essentially Same Answers (currently set to +/- 0.001) </ul>
<ul>6 decimal places</ul>
# Try It Out!
Go to Releases (on the right hand side) and download the .jar file to play. If you are not able to play, you can try copying and pasting the code in Java Online Compilers like <a href = "www.programiz.com">Programiz</a>.
